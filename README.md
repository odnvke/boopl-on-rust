### Boopl - язык без чисел
  
## Основыные функции языка:
- перемменные: хранят bool или Динамическую метку
- GOTO, IF и Метки
- операции Not, Or, And, Xor, тождество
- ввод/вывод bool`ов или UTF-8 символов

## Препроцессоры:
- (N) в начеле строки что бы повторить н-раз
- имя_{start..=end}: x_out{8..15} X x_in1{0..7} x_in2; (X - Xor)
- FUNC/CALL/RET заменяются на статические/динамические метки
- ELSE/ELSE IF заяняется на метки
- (планируется WHILE/BREAK/CONT)

## другие функции:
- импорт файлов
- 4 встроеные библиотеки

---

## Pipeline перевода в байткод и исполнение:
1. чтение файла
2. удаление комментариев/токенизация
    ```
    //рузельтат: 
      Vec<Vec<String>>
    // строки<строка<токены>>
    ```
3. препроцессоры рузультат: тот же
4. импорт файлов и повторение препроцессоров для них
5. генерация id для меток и переменных
    ```
    //рузельтат: 
      Vec<Vec<Enum>>
    // строки<строка<токены>>
    ```
6. перевод в байткод
    ```
    //рузельтат: 
      Vec<Vec<i32>>
    // строки<строка(опкод, параметры)>
    ```
7. презагрузка: заменяет метки (Статические на цисла), проверка на ошибки, добавление нужных end\'ов для if'ов

8. исполнение
